# 🎯 Number Guess Game

A beginner-friendly Python command-line game where the computer randomly generates a number between **1 and 100**, and the player attempts to guess it.

---

## ✨ Features

- Random number generation
- Higher / Lower hints
- Exception handling
- Input validation
- Quit option
- Beginner-friendly code

---

## 🛠️ Technologies

- Python 3

---

## ▶️ How to Run

Clone the repository

```bash
git clone https://github.com/hammadbabar27/PYTHON-PROJECTS.git
```

Navigate to the project

```bash
cd PYTHON-PROJECTS/Number-Guess-Game
```

Run

```bash
python main.py
```
