# 🔐 Password Generator

A simple Python application that generates secure random passwords based on the user's desired password length.

---

## ✨ Features

- Random password generation
- User-defined password length
- Strong character combinations
- Easy to use
- Beginner-friendly project

---

## 🛠️ Technologies

- Python 3

---

## ▶️ How to Run

Clone the repository

```bash
git clone https://github.com/hammadbabar27/PYTHON-PROJECTS.git
```

Navigate to the project

```bash
cd PYTHON-PROJECTS/Password-Generator
```

Run

```bash
python main.py
```
